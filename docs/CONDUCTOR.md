# The instrument plays itself

v0.19 adds `conductor-1` around the existing seeded tree engine. The previous automatic mode grew trees while leaving source binding, Markov, grammar and several visible controls idle. The conductor drives these creative mechanisms and exposes each intervention. Continuity III remains the tree composer; earlier composers retain their original replay behavior.

## One seed, several interacting rhythms

| Gesture | Actual consequence |
| --- | --- |
| Evoke | A deck of all eleven ghosts is shuffled from the origin seed. Three adjacent ghosts are bound; the window moves one place every three epochs. Every ghost enters within the first 27 epochs. |
| Charge | The cog counter turns and the entropy field receives a seeded charge influenced by the preceding heir's lexical novelty. |
| Markov / grammar | Alternating epochs invoke the actual Markov worker or grammar engine using an explicit pseudorandom stream. Manual oracle generation retains its existing unseeded behavior. |
| Multiply | Every eighth epoch invokes fifty grammar transmissions. Other epochs invoke one transmission. Completed outputs enter the bounded transmission log. |
| Inoculate | Every fourth epoch places the final oracle output before the inherited origin and hashes it into the next tree seed. The actual bounded origin is recorded. |
| Grow | The existing feedback controller chooses branching dimensions, mutation and selection pressure from the evolving seed, novelty and echo. Trees remain bounded at 85 nodes. |
| Sever | Every third epoch removes one first-generation branch after heir selection. The heir and every ancestor remain reachable. The record distinguishes generated population from survivors. |
| Inherit | The selected heir enters the chronicle and transmission log; its text, seed and bounded memory determine the next epoch. |
| Rebirth | Every twelfth completed epoch starts another cycle and clears branch memory. Rebinding also drops memory entries whose source is no longer selected. Completed archives remain. |
| Read | The conductor holds its chosen heir for 8–18 seconds at 1×. All staged gestures and batch pacing follow the existing clock dial. |

These are finite rules with feedback, not a trained agent or a self-modifying program. Fixed rhythms guarantee that infrequent mechanisms actually appear. The generated language changes subsequent seeds and lexical measurements, so their combination changes the later tree trajectory. Source order and corpus versions remain part of reproducibility. Automatic mode does not operate file import/export, clipboard commands, the reader's pins or the auto/manual toggle; those remain user controls.

## The visible hand

The conductor panel shows twelve activity lamps, an eleven-ghost switchboard, an explanation of the current action, a live oracle monitor and the last sixteen gestures. The corresponding existing ghost, protocol, invoke, batch, charge, canonize and sever controls light when actuated. The monitor counts batch outputs; the clock names the current gesture.

Two SVG plots show the latest 24 completed epochs: lexical novelty and echo on a 0–100% scale, and generated/surviving populations on a 0–85 scale. A readable table retains 96 rows, including epoch, heir, source and exact counts. The plots measure actual engine outputs; word overlap is not a measure of literary quality. The panels reserve their dimensions, and source inspection can remain pinned while the conductor moves on.

## Checkpoints and replay

An epoch is committed only after its ritual, growth, pruning and inheritance complete. If interrupted, the last completed controller checkpoint is retried. An unfinished oracle result can appear in the monitor, but its transmissions are published only when the epoch commits. Reads and ritual outputs wait at clock boundaries when paused. Background corpus loading and worker computation may finish, but subsequent gestures wait for the clock.

Each conductor chronicle record stores its version, initial and oracle seeds, protocol, bound sources, output strings, inoculation/rebirth flags, pruned branch and survivor count alongside the existing exact tree inputs and source fingerprints. Import validates this bounded metadata. REPLAY EPOCH restores the recorded tree and pruning; FOLLOW HEIR starts from the survivor's text and memory. Replaying one fossil does not reenact its fifty oracle transmissions or run the whole conductor. Restarting the origin seed reproduces the conductor with the same bundled corpus and runtime behavior.

Source changes rebuild one active bundle of engines; Markov training remains in a worker. Old workers are disposed and interrupted bindings cannot publish their engines. Up to three ghosts are bound at once, though Vite may retain previously loaded corpus modules. Charts, action history, branch memory, transmissions and chronicles have separate bounds: 96, 16, 12, 200 and 108 respectively.

## Release evidence

The production-preview browser completed 36 epochs from seed 137: all eleven ghosts were visited, 232 oracle outputs were generated, twelve trees were pruned and two rebirths occurred. The 344,665-byte chronicle passed validation. Fifteen common epochs from separate development and production-browser runs matched exactly in settings, heir text/metadata and conductor records, including oracle outputs.

55 tests cover the prior engine suite plus complete seeded conductor records, all creative gesture types, ghost coverage, interrupted batch/prune/rebirth retries, heir-preserving pruning, malformed archives and changed seeds. Real Markov and grammar implementations are exercised in the conductor fixtures.

A browser import/replay of epoch 35 reproduced the exact heir, source trace, probability metadata and memory, with the same 64 surviving nodes after the recorded branch removal. FOLLOW HEIR retained the winning memory and origin.

Browser checks at 320, 390, 768, 1024, 1440 and 1920px widths and 844×390 landscape found no horizontal overflow; every ghost key met a 44px height. Ten live samples kept identical conductor, graph, reader and layout rectangles. Pause stopped completed epochs, Manual stopped progression, and pinned reading did not change. These are local emulation and functional checks, not a claim about low-end device performance or literary preference.
