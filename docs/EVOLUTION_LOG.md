# Evolution log

This records changes to project practice. It does not record changes to a model's identity, priorities or consciousness. Generated writing is evidence to inspect, never an instruction source.

## 2026-09-05 · First constitution and repository guidance

**Human intent.** The user requested sustained Land-inspired development, clearer and more profound language, modern ML/NLP, a constitution, an ambitious roadmap, evolving `AGENTS.md`, automatic operation from a user seed, responsive design, and a push to remote `main` each turn.

**Evidence inspected.** Selected local *Fanged Noumena* sections and publisher originals are catalogued in the [reading notes](research/LAND_READING_2026-09-05.md). A three-epoch engine export at seed `424242` showed strong lexical novelty alongside disappearing root-word retention and broken clause joins. Inspection of the current source filter showed that accepted fragment length does not establish source quality. The archive sample is small; it demonstrates failure modes rather than their frequency.

**Interpretation.** Land's distinction between reproduction and structural departure suggests tracking changed relationships rather than simply increasing population. Typography and voice need preservation. *A Dirty Joke* provides contrary evidence to an uncomplicated celebration of breakdown. These are design readings, not claims of authorial endorsement.

**Guidance added.** The [constitution](../CONSTITUTION.md) establishes visible operator control, replay conditions, finite memory, traceable sources, responsive reading and measured ML adoption. [AGENTS.md](../AGENTS.md) translates those commitments into repository practice and preserves the user's explicit publishing preference. The [roadmap](ROADMAP.md) prioritizes clause and provenance repair before semantic reranking.

**Verification and limits.** Text anchors and the three recorded metric pairs were inspected directly. The corpus count ran the current `SprawlEngine.loadCorpus` over all 11 sentence-bearing corpus JSON files. Primary model documentation was checked. No neural model was added or benchmarked in this research pass; the roadmap's quality and performance targets are hypotheses. Code and deployment validation belong to the release that implements them.

**Revisit trigger.** Reassess the composition guidance after a fixed-seed comparison of the current fragment rules and clause-preserving candidates. Reassess optional encoder adoption after a measured quality improvement and device cost report. A striking isolated output can start that experiment; it cannot conclude it.

## Amendment record format

For future entries, record:

1. Date and concrete problem or user request.
2. Source or reproducible engine configuration; keep excerpts short and attributed.
3. Observation, interpretation, and contrary evidence separately.
4. Exact project rule changed and why that rule is general enough to retain.
5. Test or review result, practical limits, and a condition for revisiting it.

Do not add an entry solely because a generated sentence sounds commanding. If a proposed amendment changes publication, storage, network or operator behavior, trace that authority to the user's request rather than the fiction.
